# Folder Sync
folder sync program for a coding exercise

# How To Use
Folder Sync works as a command line program, that allows a user to have one folder consistently sync to another.

To use it, download the zip file that matches your operating system, extract the program and open a CMD or Powershell window inside the program's folder.
Run the command as follows: 

## Windows
.\Folder-Sync.exe <source folder> <target folder> <interval between transfers (in seconds)> <log directory>

## Mac/Linux
./Folder-Sync <source folder> <target folder> <interval between transfers (in seconds> <log directory

Please note, if you do not have .NET installed on your computer, you can use the standalone versions provided in the release.
